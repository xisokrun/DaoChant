## Enable Pages

1. Repo **Settings → Pages**
2. Branch: `main` → folder **`/docs`** → Save
3. Wait 1–2 minutes, open the Privacy link above

App Store Connect:

- Privacy Policy URL → `…/privacy.html`
- Support URL → `…/support.html`
